# Matrices-Java
Hola, este es un repositorio que te mostrara como se hacen 2 tipos de matrices: Una usando la funcion Random, y otra es un creador de matrices. La primera solicitara el tamaño de la matriz y lo rellenara con valores aleatorios del 1 al 10. La segunda solicita el tamaño y posteriormente los valores, despues los imprime. El vector funciona igual.
